# brokapi для Python

Тонкая обертка над ядром brokapi на Rust. Стадия: **закрытая альфа**. Проверено на имитациях брокеров, вживую нет
([Готовность](../readiness.md)), интерфейс до беты может меняться.

Обертка не придумывает своих правил. Это те же БКС, Т-Банк и Финам, те же сверка, `cid`, лимиты и ошибки, что у ядра, только
вызываются они из Python. События приходят через `async for`, деньги, цены и количества - `decimal.Decimal`, никогда `float`.
Устройство, правила и особенности брокеров общие для всех путей и лежат в общих частях книги. Здесь то, что зависит от языка:
как подключить пакет и как решить задачу кодом.

## Что нужно

- Python 3.10 или новее. Пакет один на все версии (`abi3`).
- На PyPI пакета пока нет, альфа закрытая. Пакет ставится из клона репозитория, нужен Rust 1.88 или новее (сборку делает
  `maturin`, он подтянется сам):

```bash
python -m venv .venv && . .venv/bin/activate
pip install ./crates/python
python -c "import brokapi; print(brokapi.__version__)"
```

Должна напечататься версия `0.1.0a1`. Готовые пакеты под Linux, macOS и Windows будут к бете.

## Что умеет первая версия

| Возможность | Как в Python |
|---|---|
| Подключиться к БКС, Т-Банку, Финаму | `await brokapi.connect("bcs")`, настройки из переменных окружения или аргументами |
| Стакан, сделки рынка, котировки, свечи | `order_book`, `last_trades`, `candles`, подписки `subscribe_*`, история по окнам `candle_pages` |
| Свои заявки и исполнения | `subscribe_order_state`, `subscribe_executions`, `executions` |
| Заявки | `reconcile`, `place`, `cancel`, `replace` (где брокер умеет), `order_state`, `active_orders` |
| Справочник, лот, шаг цены, статус торгов, расписание | `instrument`, `find`, `trading_params`, `trading_status`, `schedule` |
| Портфель | `portfolio`, `positions`, `balances`, подписка `subscribe_portfolio` |
| События | `async for envelope in client.events`, один поток на клиента, `brokapi.merge` для нескольких |
| Ошибки | исключения с теми же именами и текстом, что у `Error` в Rust: `Unknown`, `Rejected`, `RateLimited`, `NotReconciled`, `Degraded` и другие |
| Тесты | `brokapi.testing.mock_bcs()`, `mock_tbank()`, `mock_finam()`: имитации брокеров, на них идет каждый пример книги |

Чего в первой версии нет, и это можно добавить по запросу: стоп-заявки, любой метод брокера через `raw()`, запись и
проигрыш потока событий в файл. Для них пока есть [Rust](../rust/index.md).

## Правила, которые остаются

Обертка сохраняет обязательные правила ядра ([Контракт для агентов](../agent-contract.md)):

- торговля открывается только после `reconcile`, до него `place` поднимает `NotReconciled`
- `cid` придумывает бот (`brokapi.new_cid()`) и записывает в свой журнал до вызова `place`
- `Unknown` никогда не повторяется: после него `order_state(cid)`
- один счетчик лимитов на область брокера: `limiter=` у `connect`
- деньги, цены и количества - `Decimal`, `float` в вызове отвергается с `TypeError`

Что бывает, если нарушить каждое правило, объяснено в общих частях: [Круг команд](../orders.md), [Круг жизни](../reconcile.md),
[Лимиты](../limits.md), [Деньги, цены и количества](../numbers.md).

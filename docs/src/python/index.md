<div class="stub-label">Что это будет</div>

Тонкая обертка над ядром на Rust. Ставится командой `pip install brokapi`, пакеты под Linux, macOS и Windows. События приходят через `async for`, деньги и цены - как `Decimal`. Те же БКС, Т-Банк и Финам, те же правила заявок и сверки, что у ядра.

<div class="stub-label">Что работает уже сейчас</div>

Обертка не придумывает свои правила, она показывает правила ядра. Поэтому общие страницы верны и для Python, только код в них пока на Rust:

- [Карта: сущности и три круга](../architecture.md), [заявки](../orders.md), [сверка](../reconcile.md), [подписки](../streams.md), [лимиты](../limits.md), [деньги и цены](../numbers.md)
- [Брокеры](../brokers/README.md): БКС, Т-Банк, Финам
- [Контракт для агентов](../agent-contract.md): обязательные правила, они одни для любого языка
- [Ошибки](../errors.md) и [события](../events.md): имена те же, что у ядра
- Ядро, на котором стоит обертка, работает сейчас: [раздел Rust](../rust/index.md)

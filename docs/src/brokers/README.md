# Брокеры

Общий интерфейс одинаков для всех трех брокеров, но сами брокеры отличаются. Эта страница - сводка различий, дальше
по странице на каждого: [БКС](bcs.md), [Т-Банк](tbank.md), [Финам](finam.md).

| | БКС | Т-Банк | Финам |
|---|---|---|---|
| Протокол | REST и WebSocket | gRPC | gRPC |
| Вход | refresh-токен, из него токен доступа | один статичный токен | секрет, из него JWT, обновляется сам |
| Идентификатор инструмента | тикер и класс (`SBER`, `TQBR`) | `uid` (его отдает справочник), `figi` или тикер и класс | `SBER@MISX` (тикер и MIC) |
| Количество в заявке | целое. Единицы (штуки или лоты) **не подтверждены** | **лоты**, целое | **штуки**. Кратность лоту не проверена |
| Глубина стакана | до 20 | 1, 10, 20, 30, 40, 50 (запрошенное округляется вверх) | до 50 (режем на своей стороне) |
| Изменить заявку | да (синхронный метод БКС) | да | **нет** (метода нет в API) |
| Поток своих сделок | из потока статусов заявок | отдельный поток сделок | отдельный поток сделок |
| Свечи | все, кроме 10-минуток (`Unsupported`) | все | все, 10-минутки собираются из 5-минуток |
| Стоп-заявки | условные заявки | отдельный сервис | обычная заявка типа стоп и метод SL/TP |
| Песочница | нет | да | нет |
| Срок обычной заявки | выбирает БКС | выбирает Т-Банк | всегда «на день» |
| Где лимиты | на токен (принято) | на пользователя | на пользователя (принято) |
| Пауза перед переподключением | 0,5 с до 30 с (настраивается) | 0,5 с до 30 с | 0,5 с до 30 с |

## Что общее у всех

- Два коннектора: MD и UD. UD на один счет.
- `cid` бота и правила заявок одинаковы ([Круг команд](../orders.md)). Меняется только то, куда `cid` кладется.
- Все ответы на неясные команды - `Unknown`, повторов нет.
- Стакан приходит полным снимком.
- Шлюз команд после запуска закрыт до `reconcile`.
- `raw()` у каждого коннектора.

## Что у брокеров устроено по-разному

- **Счета.** У БКС счет задает токен, у двух остальных - `account_id`.
- **Лимиты.** Три разные области, см. [Несколько счетов и брокеров](../rust/accounts.md).
- **Единицы количества.** Если бот работает с несколькими брокерами, пересчитывайте лоты и штуки сам. Размер лота
  дает `TradingParams::lot_size`.
- **Что не поддерживает брокер.** Помечено на странице брокера. Такие вызовы возвращают `Unsupported` сразу, без
  сети.

## Что проверено

Все три брокера проверены на имитации (mock-серверы) и общим набором сценариев `brokapi-conformance`. **На настоящих
API через коннекторы не проверен ни один.** Подробная таблица - [Готовность](../readiness.md). Вопросы, на которые
ответит только живой счет, - в конце страницы каждого брокера и в [Живых прогонах](../live.md).

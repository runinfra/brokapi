<div class="stub-label">Что это будет</div>

Служба и командная строка `brokapi`. Один процесс держит связь с брокерами за все ваши боты, а боты на любом языке подключаются к нему по gRPC. Один счетчик лимитов на всех, чтобы несколько ботов вместе не превысили квоту брокера. Командная строка нужна, чтобы запустить службу, посмотреть статус и журнал. Бесплатно, ставится у себя. [CLI](../cli/index.md) (команды `brokapi status`, `brokapi book` и другие) работает через Gateway, а может и напрямую.

<div class="stub-label">Что работает уже сейчас</div>

Служба строится на том же ядре, поэтому правила заявок, сверки, подписок и лимитов для нее те же, что описаны в общих страницах. События, команды и ошибки ядра уже переводятся в serde и обратно без потерь: это нужно, чтобы они проходили границу процесса.
